# Availability and Scope

## Included

- Aggregate candidate results for the three dataset/model comparisons.
- Aggregate baseline detection metrics and evaluation scale.
- Report selection/formatting configurations and a standard-library report viewer.
- Explanatory documentation and a file checksum manifest.

## Not Included

- IBPR/BPGS implementation, feature definitions or supervision construction.
- Training, cross-fitting, parameter-selection or inference procedures.
- Neural predictor implementation, training labels or preprocessing recipes.
- Original method configurations, thresholds, seeds and selected hyperparameters.
- Per-scene or per-tree results, point arrays, prediction caches and checkpoints.
- Experimental development logs, local source paths, or private repository history.

This preview intentionally discloses benchmark identities, experiment-arm names and
aggregate numerical findings. Withholding implementation reduces disclosure of
method details but does not make these scientific findings confidential or prevent
inferences from the published comparisons.

No software licence or citation metadata is invented. Additional materials may be
released later; no publication date or venue is promised.
